# hospital--management
Python microproject for hospital-management 
Hospital Management System

Description
This project is a simple Python-based hospital management system. It simulates basic hospital operations by allowing users to add patient details, view records, assign doctors, and manage appointments.

Services Available
Patient Registration
Doctor Assignment
Appointment Booking
Patient Records Management

 Features
Add new patient details
View patient records
Assign doctors to patients
Book and manage appointments
Simple data storage using lists/dictionaries
User-friendly console interface

Technologies Used
Python 3

How to Run
Download the file
Open terminal / command prompt
Run:
Bash
python main.py
